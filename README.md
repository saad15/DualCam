# DualCam
Photo + video capture from front and back cameras at the same time (CameraX concurrent camera, Android 11+, device must support concurrent front+back).

## Get the APK (no Android Studio needed)
1. Create a new GitHub repo, upload everything in this folder (keep `.github/`).
2. Open the Actions tab > "Build APK" (runs on push) > download the `DualCam-debug-apk` artifact.
3. Unzip, install the .apk (allow "install unknown apps").

Or in Android Studio: open this folder > Build > Build APK(s).

Output: Pictures/DualCam and Movies/DualCam (one file per camera).
